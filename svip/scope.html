Publication scope

What is in this snapshot.

Complete guides, architecture notes, and reusable example source for reading and adaptation. A static demo of the documentation and APIs.

Included material

The package has all five user guides, all five architecture guides, AXI4 protocol checks, the APB usage cookbook, and Control recipes. It also contains the original public-API examples and small standalone Control example tops. Author and SPDX notices remain intact.

Runtime and source requirements

Commands and compile filelists shown in the original guides are instructions for the full SVIP workspace. Running them requires its runtime packages, UVM 1.2, VCS, and an appropriate simulator environment. This demo does not bundle the protocol implementation, control backends, build scripts, complete filelists, compliance tests, or independent peer fixtures. Example sequences can reference those runtime base classes; their complete source is presented for learning rather than claimed as a standalone simulator distribution.

The small Control example tops model a clock/reset/configuration interface and, where needed, a simple receiving register. They are reusable demonstrations, not internal DUT source. Product-specific DUTs, site configuration, credentials, and internal integration instructions are not published.

Verification and historical records

No VCS/UVM simulation, coverage run, tracker capture, or DUT acceptance run was performed to build this static snapshot. Upstream guides discuss supported profiles and refer to acceptance records; those statements remain source documentation. Historical round-by-round verification pages, logs, waveforms, hashes of private test runs, and compliance catalogs are not included here.

A guide link that originally targeted such a record leads to this section so its evidence boundary is explicit. Use the guide's declared API and protocol limits as documentation; this site does not supply a new passing simulation claim or formal protocol certification.

Protocol checking

AXI4: the protocol-checks guide describes SVIP monitor rules, raw four-state checks, dependency tracking, active byte lanes, and reset behavior. Arm BP063 / Axi4PC is a separately installed independent checker; its implementation and adapter are not bundled in this demo.

APB: the user guide and architecture describe selected ACCESS windows, wait-state stability, active byte lanes, X responses, reset abort, and RAL observations. PREADY matters in selected ACCESS; PSLVERR matters at completion. A successful bus command does not automatically prove a DUT side effect.

SPI / JTAG: the SPI architecture and JTAG architecture describe the supported profiles, ownership, sample windows, timing, reset, and frame/scan reconstruction. Numerical timing windows must match the connected device.
