What this demo establishes

This is a static, per-file source index. It is not simulator elaboration or a passing simulation result. Runtime factory overrides, dynamic instances, and exact DUT/BFM binding need runtime evidence. UVM library definitions and uvm_macros.svh are external to the fixture; the filelist intentionally treats the UVM macro include as an external library include. The parser reports 49 per-file syntax diagnostics; this index is not compilation evidence.

The portable wiki embeds source context for graph and definition browsing. Full-text source search is an upstream serve-mode feature; the complete static source browser is available here for every bundled file.
