PVKit 示例

AXI4 · CXL NATIVE · XPVKIT 0.5.5

15 个 release 场景：7 个 AXI4、8 个 CXL Native。直接打开 HTML 报告，回放真实 TUI 打印，或查看可复制的分析与 tracker 日志。所有页面和数据均为静态文件，无需安装工具。

数据为合成示例，不代表真实 DUT 性能。响应未完成场景有预期诊断。CXL 的 EMPTY 仅表示记录到的耗尽区间，未记录部分保持 UNKNOWN。
